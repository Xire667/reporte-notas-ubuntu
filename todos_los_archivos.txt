# ESTRUCTURA DE ARCHIVOS DEL SISTEMA DE GESTIÓN DE NOTAS

## ARCHIVOS PRINCIPALES

- `app.py`: Punto de entrada principal de la aplicación Flask. Inicializa la aplicación y ejecuta el servidor.
- `config.py`: Configuración global de la aplicación, incluyendo configuración de base de datos, secretos y variables de entorno.
- `requirements.txt`: Lista de dependencias Python necesarias para ejecutar el sistema.
- `init_db.py`: Script para inicializar la base de datos con datos predeterminados.
- `README.md`: Documentación general del proyecto.

## ESTRUCTURA DE LA APLICACIÓN

### Carpeta `app/`
Contiene el código principal de la aplicación Flask.

- `__init__.py`: Inicializa la aplicación Flask, registra blueprints y configura extensiones.
- `models.py`: Define los modelos de datos (ORM) utilizados en la aplicación.
- `routes.py`: Rutas principales de la aplicación.

### Carpeta `app/modules/`
Organiza la aplicación en módulos funcionales (blueprints).

#### `app/modules/admin/`
Módulo para la administración del sistema.
- `__init__.py`: Inicializa el blueprint de administración.
- `routes.py`: Define las rutas y funciones para la gestión administrativa (cursos, docentes, alumnos, ciclos académicos, etc.).

#### `app/modules/alumno/`
Módulo para la funcionalidad de alumnos.
- `__init__.py`: Inicializa el blueprint de alumnos.
- `routes.py`: Define las rutas y funciones para la vista de alumnos (ver notas, cursos matriculados, etc.).

#### `app/modules/auth/`
Módulo para la autenticación de usuarios.
- `__init__.py`: Inicializa el blueprint de autenticación.
- `routes.py`: Define las rutas y funciones para login, registro y gestión de sesiones.

#### `app/modules/docente/`
Módulo para la funcionalidad de docentes.
- `__init__.py`: Inicializa el blueprint de docentes.
- `routes.py`: Define las rutas y funciones para la vista de docentes (gestión de notas, reportes, etc.).

#### `app/modules/main/`
Módulo para las páginas principales y públicas.
- `__init__.py`: Inicializa el blueprint principal.
- `routes.py`: Define las rutas y funciones para las páginas públicas y de inicio.

### Carpeta `app/static/`
Contiene archivos estáticos (CSS, JavaScript, imágenes).

#### `app/static/main/styles/`
Hojas de estilo CSS del sistema.
- `colores_base.css`: Define las variables de color base para todo el sistema.
- `sistema.css`: Estilos generales para todo el sistema de gestión de notas.
- `admin.css`: Estilos específicos para la interfaz de administración.
- `style.css`: Estilos adicionales y personalizaciones.

#### `app/static/main/assets/img/`
Imágenes y recursos gráficos utilizados en el sistema.

### Carpeta `app/templates/`
Contiene las plantillas HTML organizadas por módulos.

#### `app/templates/global/`
Plantillas base que son extendidas por otras plantillas.
- `base.html`: Plantilla base general para páginas públicas.
- `base_sistema.html`: Plantilla base para páginas del sistema (con menú lateral, etc.).

#### `app/templates/admin/`
Plantillas para la interfaz de administración.
- `base_admin.html`: Plantilla base para todas las vistas de administración.
- `dashboard.html`: Panel principal de administración.
- `cursos.html`: Gestión de cursos.
- `docentes.html`: Gestión de docentes.
- `alumnos.html`: Gestión de alumnos.
- `ciclos.html`: Gestión de ciclos académicos.
- `notas.html`: Visualización general de notas.
- `editar_estilos.html`: Personalización de la apariencia del sistema.
- `registrar_*.html`: Formularios para registrar nuevos elementos.
- `editar_*.html`: Formularios para editar elementos existentes.

#### `app/templates/alumno/`
Plantillas para la interfaz de alumnos.
- `dashboard.html`: Panel principal de alumnos.
- `cursos.html`: Lista de cursos matriculados.
- `notas_curso.html`: Visualización de notas por curso.

#### `app/templates/auth/`
Plantillas para autenticación.
- `login_*.html`: Páginas de inicio de sesión específicas por rol.
- `role_selection.html`: Selección de rol para inicio de sesión.

#### `app/templates/docente/`
Plantillas para la interfaz de docentes.
- `dashboard.html`: Panel principal de docentes.
- `gestionar_notas.html`: Interfaz para gestionar notas de alumnos.
- `reportes.html`: Generación de reportes.
- `reporte_*.html`: Diferentes tipos de reportes.
- `alumnos_curso.html`: Lista de alumnos por curso.

#### `app/templates/main/`
Plantillas para páginas principales.
- `inicio.html`: Página de inicio pública.
- `inicio_sistema.html`: Página de inicio del sistema para usuarios autenticados.

## RESUMEN DE FUNCIONALIDADES

1. **Sistema de autenticación**: Login y registro con diferentes roles (admin, docente, alumno).
2. **Gestión administrativa**: Administración de cursos, docentes, alumnos y ciclos académicos.
3. **Gestión de notas**: Registro y visualización de notas por parte de docentes.
4. **Reportes**: Generación de reportes de notas en diferentes formatos.
5. **Personalización visual**: Sistema de temas y colores personalizables.
6. **Interfaz responsiva**: Diseño adaptable a diferentes dispositivos.
